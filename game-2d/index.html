ยินดีต้อนรับสู่ สถาบันวิจัยชีววิทยาโมเลกุล 2D สถาบันวิจัยที่เต็มไปด้วยตัวละคร AI นักวิจัยที่มีชีวิตจริง พร้อมทั้งเผชิญหน้ากับเหตุการณ์ไวรัสชีวภาพรั่วไหลในโซนนอกแล็บ!

🎮 การควบคุม

  • W A S D / ลูกศร (แป้นไทย ไ ฟ ห ก): บังคับตัวละครเดินสำรวจ
  • Shift: วิ่งเร็วเพื่อหนีซอมบี้
  • ปุ่ม E หรือปุ่ม [💬 คุย/สำรวจ]: คุยกับนักวิจัย หรือใช้งานเทอร์มินัลตอบคำถาม
  • คลิกเมาส์ / แตะหน้าจอ: สั่งเดิน หรือคลิกตัวละครเพื่อเปิดดู Memory Stream

🧟 ภารกิจตอบคำถามเอาชีวิตรอดจากซอมบี้

  • 1. ประตูกักกันโรค (Quarantine Airlock Gate): ตอบคำถาม Active Transport ภายในเวลาเพื่อเปิดประตูสู่โซนนอกแล็บ
  • 2. ป้อมปืนเลเซอร์ Caspase: ตอบคำถาม Apoptosis / p53 ภายในเวลาเพื่อยิงลำแสงเลเซอร์ทำลายซอมบี้รอบข้าง
  • 3. สถานีสังเคราะห์วัคซีนกู้โลก: ตอบคำถาม Start Codon / Translation ที่ลานดาดฟ้าเพื่อชนะเกม!

🧭 เส้นทางแนะนำสำหรับผู้เล่น & ผู้ชม (Mission Walkthrough):
  1. 1. ออกจากแล็บปลอดภัย: เดินลงมาที่ โถงทางเดินหลัก ไปยัง ประตูกักกันโรค (Airlock Gate)
  2. 2. ปลดล็อกประตูกักกันโรค: โต้ตอบเทอร์มินัล ตอบคำถาม Active Transport ภายในเวลาเพื่อเปิดประตู
  3. 3. ฝ่าเขาวงกตชีวภาพ (Bio-Labyrinth): ลัดเลาะตามทางเดินในเขาวงกต หลบการโจมตีของซอมบี้ มุ่งหน้าสู่ทางออกฝั่งขวา
  4. 4. ป้อมปืนเลเซอร์ Caspase: ตอบคำถามยีน p53 เพื่อยิงลำแสงเลเซอร์สลายซอมบี้ในพื้นที่
  5. 5. ลานอพยพดาดฟ้าสังเคราะห์วัคซีน: ตอบคำถาม Start Codon เพื่อสังเคราะห์วัคซีนต้านไวรัส กอบกู้สถาบันวิจัย!
