🎮 การควบคุม

  • W A S D / ลูกศร (แป้นไทย ไ ฟ ห ก): บังคับตัวละครเดินสำรวจ

  • คลิกเมาส์ / แตะหน้าจอ: สั่งเดิน หรือคลิกตัวละครเพื่อเปิดดู Memory Stream

🧟 ภารกิจตอบคำถามเอาชีวิตรอดจากซอมบี้

  • 1. ประตูกักกันโรค (Quarantine Airlock Gate): ตอบคำถาม Active Transport ภายในเวลาเพื่อเปิดประตูสู่โซนนอกแล็บ
  • 2. ป้อมปืนเลเซอร์ Caspase: ตอบคำถาม Apoptosis / p53 ภายในเวลาเพื่อยิงลำแสงเลเซอร์ทำลายซอมบี้รอบข้าง
  • 3. สถานีสังเคราะห์วัคซีนกู้โลก: ตอบคำถาม Start Codon / Translation ที่ลานดาดฟ้าเพื่อชนะเกม!
